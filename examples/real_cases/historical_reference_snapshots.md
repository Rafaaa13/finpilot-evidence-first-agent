# Historical reference snapshots

These snapshots are a small, manually curated set of public historical reference points. They are not a complete time series, not real-time data, not a redistribution license, and not an investment signal. Use them to start a case discussion; use an authorized CSV or an explicit provider fetch for actual calculations.

`historical_reference_snapshots.json` contains three cases:

- 2020 COVID equity shock/recovery: S&P 500 closing levels on 2020-02-19, 2020-03-23 and 2020-08-18.
- 2022 tightening/equity drawdown: S&P 500 reference closes on 2022-01-03, 2022-10-12 and 2022-12-30.
- 2022 Treasury repricing: US 10-year par yields on 2022-01-03 and 2022-12-30.

Each observation has a source URL and a note. Treat the snapshot as a citation-ready discussion aid. Do not combine it with the synthetic `DEMO` universe as if they share an issuer, currency, frequency or data vintage.

The first two cases use public reports and the FRED daily S&P 500 close series as context. The Treasury case uses the US Treasury Daily Treasury Par Yield Curve Rates pages. Before publishing or redistributing a larger dataset, review the source terms and obtain the appropriate permission.
